## Doctor block exit code
Plugin handler returns `2` when blocked.
Hermes `main.py` propagates `sys.exit(rc)` for non-zero int returns.

Prior dogfood `EXIT:0` was a **harness artifact**:
`hermes minefield doctor 2>&1 | tee …; echo $?` without `pipefail`
records tee's success (0), not hermes.

Also fixed: Minefield import moved **after** the concurrency guard so blocked
runs do not depend on `minefield` being importable and issue 0 Doctor requests.

Verified: `hermes minefield doctor` → exit 2, warning shown, requests=0.
